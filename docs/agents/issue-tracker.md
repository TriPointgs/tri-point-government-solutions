# Issue tracker

Keep specs and tickets in the local `.scratch/<feature>/` directory. Store the spec as `spec.md` and each ticket as `issues/NN-short-title.md`. Read an existing ticket by its path. Record its triage label on a `Status:` line and append follow-up notes under `## Comments`.

For a wayfinding session, keep the map in `map.md` and link its numbered tickets. Use `Type:` for the ticket type, `Blocked by:` for ticket numbers, and `## Answer` for the resolution. Record claims and resolutions separately from the triage label. Record the answer in the map when a ticket closes.

Keep `.scratch/` local. This repository is public. Publishing task text to GitHub requires a separate request.
