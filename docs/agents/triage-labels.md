# Triage labels

| Label | When to use it |
| --- | --- |
| `needs-triage` | A maintainer needs to review the ticket. |
| `needs-info` | More details are needed before work can proceed. |
| `ready-for-agent` | The task is specified and ready for an agent. |
| `ready-for-human` | The task requires a person to carry it out. |
| `wontfix` | The team has decided to close the task without implementing it. |
